Guide d'Impression & de Pliage 📖

Pour obtenir une magnifique carte d'invitation à deux volets comme chez un imprimeur, suivez ce guide simple :

1

Type de Papier

Utilisez un papier épais de type **Bristol ou Canson (250g à 300g)** de format A4, de préférence blanc mat ou ivoire texturé.

2

Configuration d'Impression

Cliquez sur "Imprimer / PDF". Dans la boîte de dialogue de votre navigateur :
• Orientation : **Paysage** (A4 Landscape)
• Marges : **Aucune** (ou minimales)
• Imprimer en recto-verso : **Oui, retourner sur les bords courts** (Short edge binding)
• Graphiques d'arrière-plan : **Activer** (indispensable pour les motifs et couleurs !)

3

Pliage précis

Une fois les deux faces imprimées, alignez les bords et marquez le pli vertical exactement au milieu (une ligne repère discrète est imprimée pour vous guider). Utilisez une règle et le dos d'un couteau pour marquer proprement le pli.
